# Grace Women Community — Anniversary Demo

A responsive one-page website demo for a Nigerian women's association celebrating its first anniversary.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project structure

```text
women_anniversary_demo/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md
```

## Demo content

All names, dates, statistics, contact details, event information, leadership names and achievements are placeholders. Replace them with the client's real information before production use.

## Running locally

Open `index.html` directly in a browser or run it through VS Code Live Server.

## Deploying to Vercel

1. Upload the project to a GitHub repository.
2. In Vercel select **Add New → Project**.
3. Import the GitHub repository.
4. Vercel should detect it as a static project.
5. Deploy.

No build command is required for this version.
